AI 광고 소재 통합 솔루션

Copyvisor 솔루션 고도화 및 ADvisor 통합 타임라인

프로젝트 핵심 방향

카피바이저로 생성하는 디자인 품질을 우선 고도화하되,
Creative Data 구조를 초반부터 설계하고 Copyvisor가 6~70% 안정화되는 시점부터
베리바이저, 모션팩토리 통합을 병렬 진행한다.

  • 완성형 플랫폼을 한 번에 만들지 않고, 작동하는 작은 버전을 반복 확장한다.
  • AI는 판단·분류·추천에 활용하고, 레이아웃·장식·효과 규칙은 디자이너가 직접 정의한다.
  • 기능 수보다 실제 광고 활용 가능성과 디자이너 수정 시간을 핵심 KPI로 본다.
  • PSD를 공통 원본으로 삼지 않는다. Creative Data를 공통 데이터로 쓰고 PSD는 출력 포맷으로 둔다.

최종 목표 구조

최종적으로는 아래 한 흐름으로 동작하는 Creative Production Platform을 목표로 한다.

INPUT

브리프 입력

기획안, 상품/서비스, 프로모션, 브랜드 정보

DIRECT

Creative Director

광고 목적·정보 우선순위·디자인 방향 결정

PARALLEL

Copy Engine

카피 구조화

Visual Engine

비주얼 구성 요소 생성

ASSEMBLE

Composition Engine

레이아웃 규칙에 따라 최종 1:1 소재 조립

REVIEW

Design Critic

결과물 평가 및 수정 포인트 제안

SOURCE

Creative Data

카피·이미지·좌표·역할·레이아웃 정보를 공통 데이터로 저장

EXTEND

Resize / Motion

베리바이저, 모션팩토리

OUTPUT

출력

PSD · JPG · MP4

모든 단계는 다음 단계가 재사용할 수 있는 구조화 데이터를 결과로 남긴다.

Creative Data 최소 구조

초기 단계에서는 복잡한 DB 스키마보다 카피바이저의 결과를 베리바이저와 모션팩토리가 다시 읽을 수 있는 최소 구조가 우선이다.

{
  "copy": {
    "headline": "",
    "highlight": "",
    "subcopy": "",
    "cta": ""
  },
  "visual": {
    "background": "",
    "product": "",
    "decorations": []
  },
  "layout": {
    "type": "L02",
    "objects": ["x", "y", "width", "height", "role", "priority"]
  }
}
copy

Copy Engine이 분해한 정보 구조. Motion에서 Headline·CTA 역할별 애니메이션의 기준이 된다.

visual

배경, 상품 처리, 장식 요소를 분리해 저장한다. 사이즈가 바뀌어도 요소 단위로 재배치할 수 있다.

layout

레이아웃 타입과 각 객체의 좌표·크기·역할·우선순위. Resize의 Responsive Rule이 이 값을 읽는다.

Creative Data가 공통 원본이고 PSD는 출력 포맷이다.

카피바이저가 60~70% 안정되는 시점부터 이 구조를 고정하고 베리바이저와 모션팩토리 연결을 시작한다.

MVP에서 의도적으로 미룰 것

  • AI가 완전 자유롭게 좌표와 레이아웃을 생성하는 기능
  • 자체 이미지 생성 모델 학습 또는 자체 PSD 파서 개발
  • 장식 요소를 전부 AI로 생성하는 구조
  • Design Critic이 자동으로 수정까지 수행하는 완전 자동 루프
  • 수십 개 스타일/사이즈/브랜드 동시 지원
  • 복잡한 계정·권한·협업·승인·버전 관리 시스템
